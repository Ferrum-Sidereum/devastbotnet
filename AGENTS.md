## Сначала прочитать

1. `docs/ARCHITECTURE_V2.md` — инварианты и принятые решения. Любое отклонение — сначала правка документа, потом код.

## Текущий скоуп

Phase 0: захват трафика, схема протокола, фикстуры, анализатор. Плюс транспортный демо-слой роя по прямому запросу оператора (11.11.2026): `demo:swarm` / `swarm:live`, квоты/IFF на уровне модульных проверок. Игровая логика ботов (FSM, навигация в рантайме, бой) — Phase 1+. Не начинать её, пока семантика `0x14`/`0x47` не подтверждена на живой сессии.

## Инварианты (не нарушать)

- **Single writer.** `SharedWorldState` мутирует только `WorldTickLoop`. Сетевые колбэки кладут `NetEvent` в очередь и не трогают мир.
- **Read-only master tap.** Никакой модификации трафика оператора: `send` вызывается с исходными аргументами. Целеуказание — через локальный GUI/оверлей.
- **Schema-first.** Никаких числовых опкодов и смещений в бизнес-коде. Всё — в `config/protocol-schema.json`. Неизвестный кадр — штатное событие, не исключение.
- **Честность статуса.** Опкод без подтверждения — `status: "hypothesis"`, имя `unknown_0xNN`. Запрещено выдавать догадку за `confirmed`.
- **Один источник времени.** TTL и тик живут по часам оркестратора; `agentTs` — только для корреляции.
- **Бюджеты.** Никаких неограниченных циклов в тике: навигация и FSM работают с явным лимитом.
- **Данные.** `sessions/`, реальные дампы и ники не коммитятся. Секреты (cookies, токены) не логируются.
- **Звук ботов.** Любой управляемый Chrome, используемый для ботов, захвата или GUI-smoke, запускается с `--mute-audio`; звук основного браузера оператора не отключать.

## Команды

```bash
npm run build
npm test
npm run fixtures:check
npm run check:userscript
npm run recorder
npm run analyze -- sessions/<dir>
npm run gui
npm run demo:simulate
npm run demo:scale -- --bots 100 --dry-run
npm run demo:swarm -- --bots 10 --seconds 20
npm run swarm:live
```

Перед сдачей: `npm test` и `npm run fixtures:check`. Для изменений сниффера — `npm run check:userscript` и smoke через `tools/sniffer/tests/sniffer.test.mjs`. Для изменений swarm-стека (`tools/demo/*`) — smoke `npm run demo:swarm -- --bots 1 --seconds 2` и симуляция `npm run demo:simulate`.

## Стиль кода

- TypeScript strict, `noUncheckedIndexedAccess`. Никаких `any` в публичных API; `unknown` + валидация.
- Модули ESM, импорты с `.js` (NodeNext).
- Числовые параметры — именованные константы в конфиге, не литералы в логике. Магические числа допустимы только в тестах.
- Ошибки парсинга — типизированный результат, не throw на границе кадра.
- Комментарии — только про инварианты и неочевидные решения, не пересказ кода.

## Запрещено

- Патчить игровой сокет оператора, подменять payload, инжектить команды в основной клиент.
- Хардкодить опкоды «по ощущениям» или подгонять тест под текущий вывод парсера без подтверждения схемы.
- Добавлять зависимости без необходимости: Phase 0 должен запускаться на Node + `ws`.
- Расширять скоуп «заодно»: рефакторинг соседних модулей, новые фичи вне Phase 0.
- Ослаблять тесты, скипать кейсы, менять expected без объяснения причины в commit message.

## Definition of done для Phase 0 изменения

1. Схема/парсер: фикстура с реальным или синтетическим кадром, `fixtures:check` зелёный, `status` честный.
2. Сниффер: синтаксис + harness-тест на перехват in/out, отсутствие рекурсии на собственном tap-сокете.
3. Анализатор: работает на сессии без падений, отчёт содержит кандидатов и корреляцию действий.
4. Документация обновлена, если изменился формат дампа, схема или инвариант.
