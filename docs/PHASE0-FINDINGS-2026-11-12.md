## Проблемы и решения

1. **Заморозка фоновых вкладок.** В headless Chrome рендерится только активная вкладка — 4 параллельных вкладки на одном Chrome не грузят меню (`body` пустой). Решение: один изолированный Chrome-инстанс на параллельный воркер захвата (`profile -wN`, эфемерный порт).
2. **Токены короткоживущие.** Конвейер «захватил всё → потом подключил» давал `BAD_DECRYPT` на всех коннектах. Решение: захват и коннект фьюзятся в одном воркере — токен используется через секунды после захвата.
3. **Нативный краш curl_cffi.** `curl_cffi 0.16.0` на Python 3.14: access violation (0xC0000005) в `WebSocket.recv()` через секунды после коннекта — процесс умирает без traceback. Решения: (а) обновление до `0.17.0` — краш уходит; (б) весь curl-IO вынесен в subprocess `tools/demo/swarm_io.py` с HTTP-контролом — оркестратор переживает даже падение IO.
4. **Одновременные handshakes.** 4 параллельных `ws_connect` в потоках крашили интерпретатор на 0.16.0. Решение: коннекты сериализованы (CONNECT_LOCK), захваты токенов остаются параллельными.
5. **Transient TLS-ошибки.** `BAD_DECRYPT` / `Connection closed abruptly` на ~30% коннектов, проходят ретраем. `demo:swarm` держит до 3 попыток на бота.
6. **Node `ws` не проходит.** Свежий токен + мгновенный коннект из Node `ws` — `socket hang up`: сервер отсекает не-браузерный TLS. Node-транспорт невозможен, `curl_cffi` обязателен (проверено probe-скриптом, удалён после эксперимента).

## Открытый вопрос: время жизни живого соединения

Бот после join получает начальное состояние и ~10–30 кадров `0x14` (heartbeat, шаг ~178 мс), затем сервер закрывает сокет (`WebSocketClosed`, пустой кадр = FIN). Наблюдения:

- без команд бот живёт ~2–10 с;
- реплей записанного `0x47` move-кадра (`475bc8b9…`, статус hypothesis) как keepalive не спасает — время жизни не изменилось;
- гипотезы: сервер ждёт валидную последовательность команд / подтверждение спавна / выгоняет дубликат identity из join-реплея.

Требует декодирования семантики `0x14`/`0x47` (Phase 0 playbook, шаг «корреляция → воспроизведение»). До этого в отчётах `demo:swarm` `bots_connected` = подтверждённые коннекты за окно запуска, а не постоянное членство в игре.

## Отчёт demo:swarm — что честно

- `bots_connected` — коннекты, подтверждённые первым входящим кадром; `same_server` — проверка пути URL.
- Позиции ботов в GUI — якоря планировщика, не декодированные координаты.
- `quota_delivered` / `combat_resolved` / `master_view_merged` — прогон реальных модулей TS (`QuotaManager`, `IFF`, `WorldStore`) на данных демо.
- Любой аварийный выход пишет отчёт с причиной (`stopped`).
